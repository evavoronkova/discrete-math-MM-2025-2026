# NetAnalisys Marp Template — Quick Reference

## Что это

Готовый Marp-темплейт для создания академических и корпоративных презентаций.
Стили вынесены в `<style>`-блок, слайды — примеры всех типов.

## Быстрый старт

1. **Установите Marp CLI** (если ещё нет):
   ```bash
   npm install -g @marp-team/marp-cli
   ```

2. **Соберите PDF** из темплейта:
   ```bash
   marp template.md --pdf
   ```

3. **Соберите HTML** (для просмотра в браузере):
   ```bash
   marp template.md -o template.html
   ```

4. **Режим live preview:**
   ```bash
   marp -w template.md
   ```

## Как кастомизировать

### Цветовая схема
В блоке `:root` в CSS поменяйте значения:
```css
--blue:  #1e22a9;  /* основной фирменный цвет */
--blue-dark: #16188a;
```

### Footer
В 4 местах (base, section, title-slide, closing-slide) найдите:
```
content: 'Ваше Имя  •  Ваша Организация  •  2026 ...'
```
и замените на свои данные.

## Типы слайдов

| Класс | Для чего | Ключевые элементы |
|-------|----------|-------------------|
| `title-slide` | Титульный слайд | `.title-label`, `h1`, `.thin-line`, `.subtitle`, `.meta` |
| `section` | Разделитель (синий) | `h1`, `.white-line` |
| `content-box` | Контентный слайд (белый) | `.section-label`, `h1`, таблицы, списки |
| `closing-slide` | Финальный слайд | `h1`, `.closing-authors`, `.closing-license` |

## CSS-компоненты

| Класс | Описание |
|-------|----------|
| `.columns` | 2 колонки (grid, gap 32px) |
| `.columns-3` | 3 колонки (grid, gap 20px) |
| `.callout` | Блок-вывод с синей рамкой |
| `.tag` | Маленький цветной чип |
| `.img-card` | Рамка для изображения |
| `.img-dual` | Два изображения рядом |
| `.fit-image` | Изображение на весь слайд |
| `blockquote` | Цитата |
| `pre > code` | Блок кода |

## Структура темплейта

```
template.md
├── META-инструкции (комментарии)
├── <style> — вся CSS-тема
├── Слайд 1: Титульный (title-slide)
├── Слайд 2: Контентный (content-box)
├── Слайд 3: Разделитель (section)
├── Слайд 4: Таблица
├── Слайд 5: 2 колонки
├── Слайд 6: 3 колонки
├── Слайд 7: Одно изображение
├── Слайд 8: Два изображения
├── Слайд 9: Callout + теги + код
├── Слайд 10: Полноэкранная диаграмма
└── Слайд 11: Закрытие (closing-slide)
```
